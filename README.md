 🇮🇳 India Air Pollution Analysis | 2021–2023

 📌 Overview

An Excel-based interactive dashboard analyzing air pollution across Indian states and cities from 2021–2023, focusing on PM2.5, PM10, NO₂, and SO₂.

 📊 Key Analysis

 State & city-wise pollution comparison
 Year-wise pollution trends
 Top 5 polluted states & cities
 Analysis of major pollutant levels
 Interactive dashboard for quick insights

 💡 Key Insights

 Identified regional variations in major pollutant concentrations.
 Compared year-wise changes in PM2.5, PM10, NO₂, and SO₂ levels.
 Highlighted high-pollution states and cities through comparative analysis.

 🛠️ Tools

Microsoft Excel · Data Cleaning · Data Analysis · Data Visualization · Dashboard Design

 🎯 Objective

To transform raw air-quality data into a clear and interactive dashboard that makes pollution patterns easier to understand.
